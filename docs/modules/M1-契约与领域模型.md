## API / Event / Error Contract

- 契约版本：`1.0.0`，canonical source 为 `packages/contracts/schema/` 下的 JSON Schema 2020-12。
- Domain resources：Patient、Examination、Image、AnnotationVersion、DatasetVersion、ModelVersion、PredictionResult、Artifact、Task、AuditEvent、User、Role。
- Command/query/event/error/Worker envelope、operation manifest 和有效示例均已落地；IPC 与 HTTP 映射同一 Application Port。
- ID 使用带资源前缀的不透明 UUID；时间为 UTC ISO 8601；文件跨边界只传 artifact ID；长任务使用 Task 与事件。
- 错误码目录和隐私/路径脱敏规则见 `docs/contracts/README.md` 与 schema。

## 数据库或文件变更

- M1 未创建或修改数据库、ArtifactStore 或运行时文件格式。
- 契约中的 Artifact owner/status 仅冻结后续 ArtifactStore 所需语义；M2 必须执行归属校验、受控生命周期和可回退的原子提交。

## 已知限制

- M1 冻结结构和跨模块语义，不实现任何 IPC、HTTP/SSE、数据库、ArtifactStore 或 Python Worker adapter。
- 版本资源的跨字段不可变约束和完整 command payload 将由后续 Application/Repository 模块在不改变本契约含义的前提下实现。
- SSE resume 的具体存储与可靠投递由整合后的 M4 LAN 与统一交付阶段决定；本阶段只冻结事件字段和兼容边界。
