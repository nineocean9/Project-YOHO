```bash
git status --short --branch

```

无法执行/按阶段延后：

- 旧系统运行测试：M0 不要求运行兼容性声明；需要时再使用 isolated clean checkout 和合成数据验证。
- 上游 source/license hash 验证：首次导入算法源码前执行。
- remote 配置、commit 与 push：目标仓库已明确，但须按用户授权单独执行。
- Python 3.11、Java 21、Maven Wrapper：归属后续模块；当前本机仅确认默认 Python 3.8.3。

## 已知限制

- 行为基线当前主要来自 dirty working tree 的只读代码推断，不等于 clean commit 的运行验证。
- 合成 fixture 只能验证协议、存储和基础图像路径，不能证明临床或算法指标。
- Source manifest 尚无导入条目；M4 不得在 provenance gate 完成前复制算法代码。
- M0 安全扫描是轻量本地校验，不替代后续 CI 专用 secret/license scanner。
