# M2 — 数据基础

## 状态

**Complete**

## 合并范围

本阶段合并原 M2 ArtifactStore 与原 M3 SQLite 与迁移。

## 目标

建立 Standalone 模式的受控文件存储和权威元数据基础：ArtifactStore 负责 artifact ID、哈希、原子写入、资源归属、软删除与回收边界；SQLite Repository 负责领域元数据、事务、版本和安全导入旧数据。

## 前置依赖

- M1 契约与领域模型已完成。
- 复用 `packages/contracts` 的 Artifact、owner、status、revision、错误和资源引用语义。

## 允许修改范围

- ArtifactStore 模块、Repository/SQLite、迁移工具、对应 adapter 与数据层测试。
- 本文件及 `CHANGELOG.md` 的当前阶段记录。

## 不在本阶段

- Python 算法和评测；Electron/Vue 页面；Spring Boot、LAN、CI、打包。
- 旧项目写入、真实患者数据、未授权数据集、模型权重或凭据。

## 交付与验收

- artifact 内容不通过绝对路径跨层传递；写入具备哈希校验、原子提交、归属校验和受控删除。
- SQLite schema、迁移、回退和旧数据导入报告可重复；禁止全量快照缺失即删除。
- 使用合成 fixture 覆盖重复导入、归属错误、损坏文件、迁移失败和回滚。
- 通过契约测试、ArtifactStore/Repository 测试和 M0 基线验证。

## 实现结果

- 新增 `@project-yoho/data-foundation`，复用 contracts `1.0.0`，未新增或修改跨模块契约。
- ArtifactStore 实现受控暂存、SHA-256/大小复核、原子提交、owner 校验、损坏隔离、软删除和显式物理回收；公开返回值不包含路径。
- SQLite Repository 使用 Node 24 内置 SQLite，仅存领域和 Artifact 元数据；资源更新使用 `expectedRevision` 乐观并发。
- migration 以事务执行，失败自动回滚并支持显式降级到目标版本。
- 旧数据导入使用 `idempotencyKey` 保存可重复报告；重复资源跳过，快照缺失不会删除现有记录。

## 数据库与文件变更

- 初始 schema 版本为 1，包含 `resources`、`artifacts`、`import_runs` 和 `schema_migrations`。
- `resources.payload_json` 保存契约 DTO；大文件内容始终位于 ArtifactStore，不写 SQLite BLOB。
- ArtifactStore 内部分为 `staged`、`objects`、`quarantine`、`trash`，这些路径不属于公共契约。
- 回退到版本 0 会删除 M2 表，只能由明确的维护操作触发；正常资源删除使用归档/软删除语义。

## 测试与验收结果

- 环境：Node.js 24.19.0、npm 11.17.0、Python 3.8.3。
- `npm run data:test`：9 项通过，0 失败。
- 覆盖：合成 PNG 写入/读取、owner 错误、损坏隔离、revision 冲突、重复导入、迁移失败回滚、显式 schema 回退。
- `npm run contracts:validate`、`npm run contracts:test`、`python scripts/m0/verify.py`：通过。

## 已知限制

- M2 提供本地数据层端口，不实现 Electron IPC、Vue、Python Worker 或 Spring adapter。
- legacy importer 接受已映射 DTO；读取旧 localStorage/MySQL 的源连接器由后续明确授权的数据迁移工作提供。
- ArtifactStore 与 SQLite 的跨资源业务事务编排属于 M3 Application Service；M2 分别保证文件提交和元数据事务边界。

## 交接给 M3

交付稳定的 artifact ID、元数据事务、版本引用和数据保护边界；下一阶段不得绕过 Repository 读写数据库或绕过 ArtifactStore 读写文件。

- 可复用入口：`packages/data-foundation/src/index.mjs`。
- 冻结点：artifact-only 文件引用、owner 全匹配、哈希复核、软删除优先、revision 冲突、幂等导入且不推断删除。
- M3 第一步应由 Application Service 编排 ArtifactStore 和 Repository，并为 Electron IPC 实现既有 operation manifest；禁止页面直接访问本模块内部路径或数据库。
